Oh My AIHub

共享自己的 Magpie，或使用朋友的模型。所有设置都在独立浏览器控制台完成，没有 AI 请求经过本插件。

打开控制台

请在运行 Magpie 的这台电脑上操作。控制台只监听本机，不会开放 Magpie 管理界面。

正在读取宿主状态…

按钮会通过 Magpie 官方选项桥请求本机默认浏览器。选项保存会重启插件宿主（所有插件共用的 Bun 进程），覆盖网可能短暂中断。旧宿主忙碌时先由原来的唯一节点处理打开请求，新宿主等待交接；不启动第二个节点。

浏览器页面过期或宿主重启后，请回到这里重新打开。通过远端 Magpie web 访问不能打开你这边的浏览器。

在其他浏览器中打开

在你选择的浏览器打开下面的普通地址，点击「配对此浏览器」，再回到本页刷新、核对八位配对码并批准。地址本身不提供登录权限。

等待控制台启动…

远端使用时，先通过你已有的 SSH 端口转发连接同一个端口；这里只接受本机回环连接。浏览器与本页的配对码必须完全一致，切勿批准他人发来的请求。

尚无等待批准的配对。

配对请求两分钟内有效。批准会让 Magpie 重启共用插件宿主；待配对请求会保留，浏览器随后建立新会话。已有会话在重启后需要重新登录。

本机状态

尚无状态快照。

本页只显示本地快照，不是实时远端检查；不显示任何 Gateway Key、网络密钥、会话票据或钱包付款对应关系。

打开偏好

只有确认由原生 Magpie 桌面启动时才自动打开；终端、SSH、无桌面环境不自动打开、不循环重试。关闭浏览器标签不会关闭节点。

4 发现与目录

目录是一份只读的签名 JSON（GET /catalog/v1）。身份是自签 Ed25519（TOFU）：签名只证明同一把私钥签过， 不证明对方是谁。指纹显示完整的 64 位十六进制，不做截断。

本页设置

首次配置（没有终端时的等价入口）

推荐在终端执行 share setup（共享）或 connect --key-file …（使用别人的）。 这个表单做同一件事：值写进 Magpie 的插件选项，宿主下次启动时用它建立覆盖网。 一旦有了网络配置，本页就不再写入网络设置——它属于配置，用 CLI 改，免得把命令行改过的结果覆盖掉。

本页偏好（随时可写，由本页自己使用）

保存会写入本插件的选项，并让 Magpie 重启插件宿主（所有插件共用的 Bun 进程）。宿主退出时会停掉它启动的 EasyTier 核心， 所以覆盖网和本地运维 API 会消失几秒；Magpie 只在有人调用时才会重新启动宿主（打开本页就会）。 重载后看诊断里的 pid 与 startedAt 就知道重启是否真的发生了。

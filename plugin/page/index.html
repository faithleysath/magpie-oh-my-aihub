Oh My AIHub

EasyTier supervisor and Gateway Key provisioner for Magpie. No AI request passes through this plugin.

Status

No snapshot yet — open this page after the host has started.

Overlay

Saving writes this plugin's options in Magpie. The supervisor reads them when the plugin host starts; Magpie restarts the host when a plugin is installed, updated or set.

Operations

This page cannot call the host (the sandbox forbids network access). Use the loopback API with the token in <magpie data>/oh-my-aihub/api-token, or the CLI: 

bun plugin/bin/ohmyaihub.ts --data <magpie data> status
bun plugin/bin/ohmyaihub.ts --data <magpie data> consumers add alice deepseek/deepseek-flash 1
bun plugin/bin/ohmyaihub.ts --data <magpie data> topup alice 1

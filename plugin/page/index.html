快速开始

1. 把工具接给 agent

打开 Magpie，进 资源库 → MCP 服务器，找到 magpie-plugin，点 agent 圆点，把常用的 agent 点亮。改完重启 agent。

2. 第一次对话

把下面这段发给 agent：

用 Oh My AIHub 帮我做首次设置，一步一步来：
0. 先检查mcp工具能否读到Oh My AIHub的工具，如果不能确定则请求用户协助
1. 先看节点状态和钱包地址，把地址和网络状态告诉我；
2. 加入网络（直接问用户索要信息）：
   名字 <网络名>，密码 <网络密码>，
   初始节点 <可选>，是否开启**secure mode**，是否；
   入网后确认网络已经连上；建议用户给自己的节点取个名字存到地址簿。
3. 列出本机可以共享的模型和价格，
   问我共享哪些，然后按我选的共享，用户可以选择暂时不共享任何模型；
4. 汇总网络里别人的模型和价格。
5. 后续使用建议：先给节点钱包留一点原生币当 gas（BSC 要 BNB，Base 要 ETH）；
   要给别人充值必须由这个钱包自己转出去，从交易所直接提到对方地址对方收不到额度。
不要动钱，不要导出私钥；参数不确定先问我。

首次入网要下载 EasyTier，几十秒很正常。agent 说还在启动时，让它继续查状态。

只想用别人的模型？第 3 步回答「不共享」就行。

常用说法

不用记工具名，直接说目的。名字先存进地址簿，后面就只说名字。

看状态

  • 「用一句话总结现在的状态」
  • 「我的节点钱包地址是什么？两条链上还有多少 USDC 和 gas？」

入网和身份

  • 「帮我加入 EasyTier 网络：名字 X，密码 Y，初始节点 Z。这个网开了 secure mode。」
  • 「把我的节点叫『美西节点』，让网络里其他人看目录时能看到这个名字。」
  • 「用 TUN 模式跑」（默认就是；没有 root 会自动回退到 no-TUN。服务器上还要放行 tun 设备：ufw allow in on tun0）
  • 「帮我装 root 守护进程，让 Mac 也能用 TUN」（Mac 上会弹一次系统管理员密码框；装好后再 join_network 一次，节点就以 TUN 运行，别再弹窗）
  • 「把节点私钥导出到 /Users/me/omai.key，不要打印私钥；换机器时告诉我怎么导入。」

地址簿

  • 「把 0xabc… 存成“张三”，备注“xxx”。」
  • 「地址簿里都有谁？把名字和地址列出来。」
  • 「张三换成新地址 0xdef… 了，改一下地址簿。」
  • 「删掉地址簿里的张三。」
  • 「给张三充 5 USDC（Base）。」——直接说名字就行，agent 会先把名字换成地址再转。

共享

  • 「列出可以共享的模型和价格，我选 A、B 共享。」
  • 「停止共享所有模型，保留网络连接。」
  • 「列出所有申请者，谁在等我批准？」
  • 「批准张三使用 A、B；余额不够就告诉我还差多少。」
  • 「拒绝张三的申请，备注“暂时不开放”。」
  • 「撤销张三的访问，确认 Key 已经删掉。」

用别人的模型

  • 「看看网络里有谁在线、共享了什么模型、什么价格，整理成表。」
  • 「我想用张三的 A 模型，帮我申请；批了就直接连接。」
  • 「看看张三批了没有；」
  • 「列出我所有的外部连接：模型、剩余额度、状态。」
  • 「断开张三，告诉我会不会影响其他连接。」
  • 「对方换了地址，重新找一遍再重连。」
  • 「连接成功了，但 Magpie 里看不到模型，查一下差在哪。」

钱

  • 「给张三充 5 USDC（Base），先查余额和 gas 再发。」
  • 「把 10 USDC 转到 0xdef…（BSC），先告诉我余额和预计 gas。」
  • 「列出最近的入账和出金，标出还没确认的和已经回滚的。」
  • 「有人给我转了钱、但没申请访问，把地址和金额列出来。」
  • 「我给他打了钱，但他那边的额度没涨，看看是哪一步没到。」
  • 「这笔钱是从交易所提的，为什么对方说没收到？」

出问题

  • 「查一下卡在哪一步、报了什么错。」
  • 「目录里为什么没有我要共享的模型？」（价格写不进目录的模型不共享，让 agent 说原因）
  • 「我的调用被 429 或 401 了，查剩余额度和授权状态，告诉我该充值还是重新申请。」
  • 「连接断了，先看对方还在不在，再决定重连。」
  • 「这笔交易的哈希是 0x…，帮我核对上链没有；不要重发。」
  • 「哪条链上的 gas 不够？告诉我补哪种原生币。」

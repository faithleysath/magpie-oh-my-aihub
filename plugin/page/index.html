Oh My AIHub

Oh My AIHub 让 Magpie 加入一个私有的 EasyTier 网络，和网络里的人互相共享模型。共享的模型按 Magpie 里的价格计费；用别人的模型，按对方的价格从你充值的额度里扣。没有自己的界面，所有操作都由 agent 通过 MCP 工具完成。

整体思路

  • 共享：把本机原生模型和价格公布到网络。
  • 使用：发现别人的模型，申请、对方批准，自动变成你 Magpie 里的一条 Remote Magpie。
  • 付费：往对方地址转 USDC，插件按付款地址记账，额度 = 累计充值。
  • 身份：每个节点一个 EVM 钱包，目录和申请都用它签名。

快速开始

1. 把工具接给 agent

打开 Magpie，进 资源库 → MCP 服务器，找到 magpie-plugin（本插件），点 agent 圆点，把常用的 agent 点亮。改完重启 agent。

agent 拿到的工具名取决于 MCP 路由：

  • 关闭：本插件单独一条，工具名是 status、wallet…。
  • 开启：agent 只拿到一个 magpie 服务器，工具名是 magpie-plugin__status。

手工加服务器：

  • 全部插件：http://127.0.0.1:3425/mcp/magpie/tools
  • 只本插件：http://127.0.0.1:3425/mcp/magpie/tools/magpie-plugin
  • MCP 路由：http://127.0.0.1:3425/mcp/magpie/hub/<agent>

本机 agent 默认免 Gateway Key。别的机器上的 agent 要调这些工具，需要在 Magpie 里打开局域网共享（Share on local network），并给它一个 Gateway Key。

2. 第一次对话

准备网络名、网络密码，想好共享哪些模型。把下面这段发给 agent：

用 Oh My AIHub 帮我做首次设置，一步一步来：
1. 先看节点状态和钱包地址，把地址和网络状态告诉我；
2. 我加入网络：
   名字 <网络名>，密码 <网络密码>，
   初始节点 <可选>；
   入网后确认网络已经连上；
3. 列出本机可以共享的模型和价格，
   问我共享哪些，然后按我选的共享；
4. 汇总网络里别人的模型和价格。
不要动钱，不要导出私钥；参数不确定先问我。

网络方说这个网开了 secure mode，就把这句话一起说：“这个网开了 secure mode”。agent 会在入网时带上 secureMode:true，本机会自己生成一对密钥存在 easytier/secure-key.json，你不用和任何人交换密钥。

好的 agent 会先读状态，再问你要网络名和密码；入网后才列模型、做发现。

入网成功的标志是状态里 peers 不为空（能看到种子或伙伴节点）。state:"online" 只说明 EasyTier 核心跑起来了，不代表已经连上别人：网络开着 secure mode 而你这边没开时，就是这个样子（核心在跑、peers 一直空）。发布端口里有 3426 和 3425 只说明本机在对外公布，不代表已经连上；发布端口为空只说明本机没有可用的局域网地址，别人看不到你，其他功能正常。

首次入网要下载 EasyTier，几十秒很正常。agent 说还在启动时，让它继续查状态。

只想用别人的模型？第 3 步回答「不共享」就行。

常用说法

不用记工具名，直接说目的。下面每一条都可以发给 agent；把 A、B、张三、0xabc… 换成你的模型、名字和地址。名字先存进地址簿，后面就只说名字。

看状态

  • 「用一句话总结现在的状态：网络、共享、连接。」
  • 「我的节点钱包地址是什么？两条链上还有多少 USDC 和 gas？」

入网和身份

  • 「帮我加入 EasyTier 网络：名字 X，密码 Y，初始节点 Z。这个网开了 secure mode。」
  • 「顺便给我开监听，让别的节点能直连我，不要全走中继。」（对应 listen:true；开了之后要在主机防火墙放行 11010 的 tcp 和 udp）
  • 「用 TUN 模式跑」（默认就是；没有 root 会自动回退到 no-TUN。服务器上还要放行 tun 设备：ufw allow in on tun0）
  • 「帮我装那个 root 守护进程，让 Mac 也能用 TUN」（Mac 上会弹一次系统管理员密码框；装好后再 join_network 一次，节点就以 TUN 运行，别再弹窗）
  • 「把节点私钥导出到 /Users/me/omai.key，不要打印私钥；换机器时告诉我怎么导入。」

地址簿

  • 「把 0xabc… 存成“张三”，备注“提供方 · Base”。」
  • 「地址簿里都有谁？把名字和地址列出来。」
  • 「张三换成新地址 0xdef… 了，改一下地址簿。」
  • 「删掉地址簿里的张三。」
  • 「给张三充 5 USDC（Base）。」——直接说名字就行，agent 会先把名字换成地址再转。

共享

  • 「列出可以共享的模型和价格，我选 A、B 共享。」
  • 「停止共享所有模型，保留网络连接。」
  • 「列出所有申请者，谁在等我批准？」
  • 「批准张三使用 A、B；余额不够就告诉我还差多少。」
  • 「拒绝张三的申请，备注“暂时不开放”。」
  • 「撤销张三的访问，确认 Key 已经删掉。」

用别人的模型

  • 「看看网络里有谁在线、共享了什么模型、什么价格，整理成表。」
  • 「我想用张三的 A 模型，帮我申请；批了就直接连接。」
  • 「看看张三批了没有；批了但没 Key 就告诉我还差多少充值。」
  • 「列出我所有的外部连接：模型、剩余额度、状态。」
  • 「断开张三，告诉我会不会影响其他连接。」
  • 「对方换了地址，重新找一遍再重连。」
  • 「连接成功了，但 Magpie 里看不到模型，查一下差在哪。」

钱

  • 「给张三充 5 USDC（Base），先查余额和 gas 再发。」
  • 「把 10 USDC 转到 0xdef…（BSC），先告诉我余额和预计 gas。」
  • 「列出最近的入账和出金，标出还没确认的和已经回滚的。」

出问题

  • 「查一下卡在哪一步、报了什么错。」
  • 「我的调用被 429 或 401 了，查剩余额度和授权状态，告诉我该充值还是重新申请。」
  • 「连接断了，先看对方还在不在，再决定重连。」
  • 「这笔交易的哈希是 0x…，帮我核对上链没有；不要重发。」
  • 「哪条链上的 gas 不够？告诉我补哪种原生币。」

agent 报出 E 开头的错误码时，把错误原文贴回去，让它按上面的顺序查。

需要知道的

  • 充值：必须从自己的节点钱包付给提供方。交易所直接提到提供方地址，钱记在交易所名下，你用不上。
  • 到账：不是即时。BSC 等 15 个确认，Base 等最终确认，插件每 15 秒扫一次。
  • 私钥：不会通过工具返回；导出只写到你指定的文件，不会打印出来。导出后，能读本机文件的 agent 仍然能读到它。
  • 网络：密码是入网门；密码对上但 peers 一直是空的，多半是网络开了 secure mode 而你没开。secure mode 下每对节点各自协商密钥，中继也解不开；普通模式下全网共用一把来自密码的密钥，中继能解。两种情况覆盖网里的 HTTP 都是明文应用层。地址不是身份，目录和申请靠签名。
  • 能不能被计费：共享方跑在 TUN 模式时，对端连接带的是它的覆盖网地址，Magpie 能按 Gateway Key 收费；跑在 no-TUN 时对端会被重写成 127.0.0.1，Magpie 当本机免 Key，所以插件干脆不公布 3425（status 里的 publishedPorts 只有 3426）。status.network.mode 写的就是当前模式。
  • 价格：共享出去的模型公布四段价（输入 / 输出 / 缓存读 / 缓存写，USD / 每百万 tokens）。阶梯价和高峰价也会一起公布（门槛是多少、高峰几倍），别人能看到全貌；一个算不出来的价格不会被共享。真实扣费在提供方的 Magpie 里，目录只负责公布。
  • 转账和断开：转账没有二次确认、没有白名单；断开连接会重启 EasyTier，其他连接短暂中断。
  • 额度：价格改了，剩余额度会跟着变。429 是额度用完，充值即恢复；401 是被撤销，要提供方重新批准。
  • 身份：同一个钱包 = 同一个账户；两台机器用同一个私钥，余额共享。

工具

需要查工具名时看这里。工具名取决于接入方式：路由关闭时是 status，路由开启时是 magpie-plugin__status，手工加全部插件地址时是 magpie-plugin_status。

  • 节点：magpie-plugin_status、magpie-plugin_wallet、magpie-plugin_wallet_import、magpie-plugin_wallet_export、magpie-plugin_join_network、magpie-plugin_network_daemon
  • 地址簿：magpie-plugin_contacts
  • 共享：magpie-plugin_native_models、magpie-plugin_share_models
  • 发现与申请：magpie-plugin_discover、magpie-plugin_request_access、magpie-plugin_connect_provider、magpie-plugin_disconnect_provider、magpie-plugin_connections
  • 审批：magpie-plugin_consumers、magpie-plugin_approve_request、magpie-plugin_reject_request、magpie-plugin_revoke_consumer
  • 钱：magpie-plugin_send_payment、magpie-plugin_history

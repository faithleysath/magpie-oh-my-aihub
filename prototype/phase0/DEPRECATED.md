# Deprecated design note

This directory is a preserved Phase 0 experiment from before the native Gateway Key quota decision. The separate HTTP admission, streaming proxy and local charging ledger **are not the target implementation**. Its tests can pass without validating Magpie source semantics or EasyTier networking. Do not deploy it or use it for real payments. Refer to ../../docs/ARCHITECTURE.md and ../../docs/VALIDATION.md instead.
